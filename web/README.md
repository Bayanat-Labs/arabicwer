# arabicwer web page

A static page that scores Arabic transcripts in the browser with the JavaScript implementation of arabicwer. It is published as the Hugging Face Space [Bayanat-Labs/arabicwer](https://huggingface.co/spaces/Bayanat-Labs/arabicwer).

| File | What it is |
|---|---|
| `arabicwer.js` | the scorer: policies, word split, alignment (rule A01) and measures; same results as the Python package |
| `policies.js` | the policy files, generated by `scripts/build_web.py` |
| `lib/` | the JavaScript port of arabic-normalize (Apache-2.0, commit dcc7f31cc5ae8b7b09e3de8401dcebe7aabc0240), with its Unicode 18.0.0 tables |
| `index.html`, `app.js`, `style.css` | the page; English by default, Arabic with the toggle or `?lang=ar` |
| `compute.js`, `worker.js` | one scoring request, run in a Web Worker started from a `blob:` URL |
| `examples.js` | the worked example (pairs from the dev fixtures) |
| `fonts/` | IBM Plex Sans Arabic, SIL OFL 1.1 |
| `privacy_check.py` | Playwright check: scores match the fixtures, no network request after load, no storage, right-to-left Arabic interface, no sideways scrolling at 1280 and 375 pixels |

Run it locally with any static server, for example `python -m http.server -d web 8000`, then open http://127.0.0.1:8000/. The Content-Security-Policy in `index.html` (`connect-src 'none'`) forbids network connections from the page and the worker; nothing you paste is uploaded or stored.

```bash
python scripts/build_space.py /tmp/arabicwer-space        # the Space folder, with its card and MANIFEST.json
python web/privacy_check.py /tmp/arabicwer-space           # needs playwright and Chromium
node scripts/crosscheck.mjs fixtures/dev.jsonl fixtures/acceptance.jsonl
```
