ArabicWER: Arabic WER and CER calculator

Paste reference and hypothesis transcripts, or upload a TSV file, and see the word and character error rates under six named, versioned normalisation policies side by side, with a word-by-word diff.

Scoring runs in your browser. Your text is not uploaded, stored or logged.

The Arabic text has not yet been reviewed by a native Arabic writer; the English governs.

Transcripts

One utterance per line. Line 1 of the reference is scored against line 1 of the hypothesis, and so on.

A UTF-8 file with one pair per line: id, reference and hypothesis separated by tabs (or reference and hypothesis only). A first line "id, reference, hypothesis" is treated as a header. Up to 10 MiB and 10,000 pairs. The file is read in this browser tab only.

Scores under every policy

Policy WER CER S D I N Policy SHA-256

Corpus rates: all errors divided by all reference words (or characters). S substitutions, D deletions, I insertions, N reference words. A pair with an empty reference has no rate of its own; its insertions still count.

The six policies

Each policy is an immutable JSON file identified by its SHA-256. Any change in behaviour gets a new policy id; arabicwer-1 policies never change.

How it is computed

  1. Each policy normalises both texts with arabic-normalize, using Unicode 18.0.0 data bundled with the page, so the result does not depend on your browser.
  2. Words are the runs of characters between white space. Characters for CER are the code points of the words joined by single spaces.
  3. Words (or characters) are aligned with the Levenshtein distance. When several alignments cost the same, the one that keeps more matches is used, and the rule is written in the specification so that every implementation agrees.
  4. WER = (S + D + I) / N, summed over all pairs before dividing. Under the raw policy, for space-separated text with a non-empty reference, the WER and CER equal those of jiwer 4.0.0.
  5. The page gives the same numbers as the Python package arabicwer on every conformance fixture.
